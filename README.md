# 📚 Studix01.net - Free Online Learning Platform

A modern, interactive learning platform for students with AI-powered tutoring, quizzes, and subject-specific resources.

## 🌟 Features

- **6 Subject Areas**: Mathematics, Physics, Chemistry, Biology, English, Geography, ICT
- **Interactive Quizzes**: Practice and test your knowledge
- **AI Tutor**: Ask questions and get instant explanations
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Modern UI**: Clean and professional interface

## 🚀 Quick Start

### Local Development

```bash
# Install dependencies
npm install

# Start the server
npm start

# Open browser to http://localhost:3000
```
